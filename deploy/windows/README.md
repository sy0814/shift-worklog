# 工作记录系统 · Windows 部署指南（初学者版）

**语言 / Jezik / Language：** 中文 · [Srpski](README.sr.md) · [English](README.en.md)

这份指南一步一步教你把「工作记录系统」装到一台 Windows 电脑上，让全厂的手机和电脑都能用。**不需要懂编程**，照着做就行。每一步都写了「怎么确认做对了」，没做对就不要往下走。

> 预计用时：第一次 **1～2 小时**（大部分时间在等下载和安装）。

## 1. 先了解几个词

| 词 | 是什么意思 |
|---|---|
| **服务器电脑** | 用来运行系统的那台 Windows 电脑。它要一直开着，大家的手机和电脑都连到它。 |
| **IP 地址** | 服务器电脑在厂区网络里的「门牌号」，例如 `192.168.1.50`。手机就是用这个地址找到系统的。 |
| **固定 IP** | 让服务器电脑的门牌号不变。如果门牌号变了，手机就找不到系统了。 |
| **端口 80 / 443** | 网页服务用的两个「入口」。80 是普通网页，443 是加密网页（HTTPS）。别的程序不能占用它们。 |
| **HTTPS 和证书** | HTTPS 是加密的网页连接。手机要先装一次本系统的「证书」，才会信任这个加密连接；不装的话浏览器会提示「不安全」。 |
| **PowerShell** | Windows 自带的命令窗口，用来运行安装脚本。 |
| **管理员身份** | 用 Windows 的最高权限运行程序。安装软件、注册服务都需要它。 |
| **服务** | 在后台自动运行的程序。电脑开机后自动启动，不用人去点开。 |
| **PostgreSQL** | 数据库软件，系统的所有记录都存在里面。 |
| **DeepSeek API Key** | 一串密钥，系统用它调用 DeepSeek 做中、塞、英翻译和 AI 分析。没有它系统也能用，只是不会自动翻译。 |

## 2. 准备清单

开始前请逐项确认：

- [ ] **一台 Windows 10 或 Windows 11 电脑**，64 位，内存 8 GB 以上，硬盘剩余 50 GB 以上。最好用有线网络。
- [ ] 这台电脑可以 **一直开着**（不关机、不睡眠）。
- [ ] 你有这台电脑的 **管理员账户** 的密码。
- [ ] 这台电脑 **能上外网**（能打开 https://www.baidu.com 或 https://www.google.com）。安装时要下载软件；平时翻译也要用外网。
- [ ] 手机连厂区 Wi-Fi 时，能和这台电脑互相访问（一般在同一个厂区网络里就可以；不确定的话问网管）。
- [ ] 能登录 GitHub 下载本系统（仓库是私有的，需要仓库所有者给你访问权限）；或者有人用 U 盘把程序包拷给你。
- [ ] （可选）DeepSeek API Key。没有的话可以先装，之后再在网页里填。
- [ ] （建议）一个 U 盘或第二块硬盘，用来放备份。

## 3. 第一步：准备服务器电脑

### 3.1 查看这台电脑的 IP 地址

1. 按键盘上的 **Win + R**，输入 `cmd`，按回车，会打开一个黑色窗口。
2. 输入 `ipconfig`，按回车。
3. 找到正在使用的网卡（有线一般叫「以太网」，无线叫「WLAN」），看 **IPv4 地址** 那一行，例如 `192.168.1.50`。
4. **把这个地址记下来**，后面要用很多次。

### 3.2 让 IP 地址固定不变（重要）

IP 地址变了，所有手机就都连不上了。两种办法选一种：

- **办法 A（推荐）：请网管在路由器里给这台电脑「绑定 IP」**（也叫 DHCP 保留）。告诉网管这台电脑的名字和上面查到的 IP 即可。
- **办法 B：自己设置静态 IP。** 不熟悉网络的话不建议自己改，改错了这台电脑会上不了网。如果一定要改：设置 → 网络和 Internet → 以太网 → IP 分配 → 编辑 → 手动 → 打开 IPv4，填上 IP 地址、子网前缀长度（一般是 24）、网关、DNS（这几个值问网管）。

### 3.3 确认 80、443 端口没被占用

大多数电脑不用管这一步。只有装过网站类软件（例如 IIS）的电脑可能会占用。安装脚本会自动检查，被占用时会告诉你是哪个程序。

如果是 IIS：控制面板 → 程序 → 启用或关闭 Windows 功能 → 取消勾选「Internet Information Services」→ 确定 → 按提示重启电脑。

### 3.4 关于睡眠

安装脚本会自动关掉「接通电源时的睡眠」。如果是笔记本电脑，请一直插着电源，并且**不要合上盖子**（或在电源设置里把「合上盖子时」改成「不采取任何操作」）。

## 4. 第二步：安装 PostgreSQL 数据库

1. 用浏览器打开 <https://www.enterprisedb.com/downloads/postgres-postgresql-downloads>。
2. 在 **PostgreSQL 17** 那一行，点 **Windows x86-64** 下面的下载按钮，下载安装程序（文件名类似 `postgresql-17.x-windows-x64.exe`）。
3. 双击运行。如果 Windows 问「是否允许此应用对你的设备进行更改」，点 **是**。
4. 安装向导里每一步这样选：

| 安装向导页面 | 怎么做 |
|---|---|
| Setup / 欢迎页 | 点 **Next** |
| Installation Directory（安装位置） | 不用改，点 **Next** |
| Select Components（选择组件） | 保持默认，点 **Next**（Stack Builder 可以取消勾选，用不到） |
| Data Directory（数据位置） | 不用改，点 **Next** |
| **Password（密码）** | **设置 postgres 超级用户的密码，输入两遍。一定要记住！** 后面安装脚本要用。建议写在纸上，交给负责人保管。 |
| Port（端口） | 保持 **5432**，点 **Next** |
| Advanced Options（区域设置） | 保持 Default locale，点 **Next** |
| Pre Installation Summary | 点 **Next** |
| Ready to Install | 点 **Next**，等几分钟 |
| Completing（完成） | **取消勾选**「Launch Stack Builder at exit」，点 **Finish** |

**怎么确认装好了：** 按 Win + R，输入 `services.msc` 回车，在服务列表里能找到 **postgresql-x64-17**，状态是「正在运行」。

## 5. 第三步：下载系统程序

**用 GitHub 下载：**

1. 用浏览器登录 GitHub，打开本系统的仓库页面（向负责人要地址）。
2. 点绿色的 **Code** 按钮 → **Download ZIP**。
3. 下载完成后，在「下载」文件夹里找到 ZIP 文件，**右键 → 全部解压缩**，解压到 `D:\shift-worklog`（没有 D 盘就用 `C:\shift-worklog`）。

**用 U 盘拷贝：** 把程序文件夹整个复制到 `D:\shift-worklog`。

**怎么确认做对了：** 打开 `D:\shift-worklog`，里面能直接看到 `backend`、`frontend`、`deploy` 这几个文件夹。

> 注意：解压后有时会多套一层文件夹（例如 `D:\shift-worklog\shift-worklog-master\backend`）。这样也没关系，后面的命令里把路径改成实际的位置就行。

## 6. 第四步：运行安装脚本

### 6.1 用管理员身份打开 PowerShell

- **Windows 11：** 右键点屏幕左下角的「开始」按钮 → **终端(管理员)**。
- **Windows 10：** 右键点「开始」按钮 → **Windows PowerShell(管理员)**。

如果问「是否允许此应用对你的设备进行更改」，点 **是**。窗口标题里应该有「管理员」字样。

### 6.2 输入命令

在窗口里**一行一行**输入下面的命令，每行输完按回车。可以复制粘贴：在 PowerShell 窗口里点右键就是粘贴。

第一行：允许本窗口运行脚本（只对这个窗口有效，关掉就恢复）：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```

第二行：进入程序所在的文件夹（路径按你实际解压的位置改）：

```powershell
cd D:\shift-worklog\deploy\windows
```

第三行：开始安装：

```powershell
.\install.ps1
```

### 6.3 回答脚本的问题

脚本会显示「==> 1/9 ……」到「==> 9/9 ……」共九个步骤，中间会问你几个问题：

| 屏幕上的提示 | 怎么回答 |
|---|---|
| 手机用哪个地址访问？直接回车 = 用上面检测到的 | 看上面「检测到：」后面的地址，里面有你在 3.1 记下的 IP 的话，**直接按回车**。不对的话手动输入 IP，例如 `192.168.1.50`。 |
| 请输入安装 PostgreSQL 时设置的 postgres 密码 | 输入第 4 步设置的密码。**输入时屏幕上只显示 `*` 号，这是正常的。** |
| 设置系统管理员 admin 的登录密码（至少 8 位） | 给网页的管理员账号 admin 设一个密码，**至少 8 位**，记下来。不够 8 位会让你重新输入。 |
| DeepSeek API Key（可以先直接回车……） | 有 Key 就粘贴进去，没有就**直接按回车**，以后在网页里填。 |
| 备份放哪里？…… | 有第二块硬盘就输入例如 `D:\WorkRecordBackup`；没有就直接按回车（会放在 `C:\WorkRecord\backups`）。 |

第一次运行时，脚本会自动下载安装 Python 和 Node.js 等软件，**可能要 10～30 分钟**。中间窗口长时间没有新输出也是正常的，不要关窗口。

### 6.4 怎么确认装好了

最后看到绿色的 **「安装完成！」**，下面有类似这样的内容：

```
安装完成！
  手机 / 电脑先打开   http://192.168.1.50/install   安装证书（只需一次）
  然后访问           https://192.168.1.50
  管理员账号         admin（密码是刚才设置的）
```

**截图保存这一段**，后面要用。

### 6.5 如果出现红色的错误

- 脚本会停下来，用中文写明是哪一步、什么原因，大部分会告诉你怎么处理。
- 按提示处理后，**再运行一次 `.\install.ps1` 就行**。已经完成的步骤会自动跳过，已经填过的密码不会再问。
- 不知道怎么处理：**把整个窗口截图**发给技术负责人。

## 7. 第五步：在服务器电脑上第一次登录并设置

### 7.1 在服务器电脑上安装证书

1. 在服务器电脑上用 Edge 或 Chrome 打开 `http://你的IP/install`（例如 `http://192.168.1.50/install`）。
2. 点 **① 下载证书**，下载 `workrecord-ca.crt`。
3. 双击下载的文件 → **安装证书** → 选 **本地计算机** → 下一步 → 选「**将所有的证书都放入下列存储**」→ 浏览 → 选 **受信任的根证书颁发机构** → 确定 → 下一步 → 完成。
4. **关掉浏览器，重新打开**。

> 小技巧：在服务器电脑本机上，也可以直接打开 `http://127.0.0.1:8000`，不用证书。这个地址只在这台电脑上能用，适合排查问题。

### 7.2 登录

打开 `https://你的IP`，地址栏应该显示一把锁，没有「不安全」的提示。用 **admin** 和你设置的密码登录。

### 7.3 第一次必做的设置

登录后，在顶部菜单「**管理**」里依次完成：

1. **账号**：系统已经建好了班长账号（`t1_leader1`～`t4_leader1`，`day_leader1`～`day_leader3`），**初始密码和用户名一样，非常不安全**。
   - 在「管理 → 账号管理」里点每个账号的「重置密码」，改成新密码，再通知各位班长。
   - 每个班长账号对应「员工名册」里的一个人（名字先和账号一样，比如「t1_leader1」）：在员工名册里把名字改成班长的真名；如果名册里本来就有这个人，在「账号管理」页点「改关联」接到他身上，再把多出来的那条停用。
   - 其他人的账号在「员工名册」里点「账号」开：班长、副班长用用户名 + 密码；成员用「班组账号」（登录时选班组 → 点自己的头像 → 输入个人密码）。每个角色能做什么在「管理 → 角色权限」里设置。
2. **员工名册**：点「批量添加」，选好班组，每行粘贴一个人名，保存。每个班组都要做一遍。
3. **排班**（顶部菜单「排班」）：看「排班日历」，确认今天各班组的班次和实际情况一致。不一致的话在「班组管理」里编辑对应班组的循环（几天一循环、每天上什么、循环第 1 天，管理员）。在「节假日 / 调休上班」里录入法定节假日。
4. **系统设置**：
   - 如果安装时没填 DeepSeek Key：在「API Key」里填入，点「**测试连接**」，看到绿色「连接正常」和三种语言的示例翻译后，点「**保存**」。
   - 「警示设置」里可以改「超过多少小时未完成就标红」。
5. **术语表**：系统已经内置了 51 个选矿和电气术语。可以请塞方同事校对：点「导出 CSV」给他们，改完后点「导入 CSV」。

## 8. 第六步：让手机用起来

每部手机只需要做一次。也可以把下面的步骤打印出来发给班长。手机上打开 `http://你的IP/install` 也能看到中、塞、英三语的同样说明。

### 8.1 安卓手机

1. 手机连上厂区 Wi-Fi。
2. 用 **Chrome** 打开 `http://你的IP/install`，点 **① 下载证书**。
3. 打开手机的 **设置**，在顶部搜索框里搜「**证书**」，找到「**安装证书**」或「**CA 证书**」。不同品牌的位置不一样，常见路径：设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书。
4. 手机提示风险时选「**仍然安装**」，然后选择刚下载的 `workrecord-ca.crt`。
5. 回到 Chrome，打开 `https://你的IP`，用班长账号登录。
6. 点 Chrome 右上角 **⋮** → **添加到主屏幕** → 添加。以后从桌面图标打开就行。

### 8.2 苹果 iPhone / iPad

1. 连上厂区 Wi-Fi。
2. **必须用 Safari**（不能用微信或别的浏览器）打开 `http://你的IP/install`，点 **① 下载证书**，选「**允许**」。
3. 打开 **设置**，最上面会出现「**已下载描述文件**」，点进去 → 右上角 **安装** → 输入锁屏密码 → 再点 **安装**。
   - 如果没看到：设置 → 通用 → **VPN 与设备管理**，在里面找到这个描述文件。
4. **这一步最容易漏：** 设置 → 通用 → **关于本机** → 拉到最下面 → **证书信任设置** → 把本系统证书后面的**开关打开** → 继续。
5. 用 Safari 打开 `https://你的IP`，登录。
6. 点 Safari 底部的 **分享按钮**（方框加向上的箭头）→ **添加到主屏幕** → 添加。

### 8.3 用起来的小提示

- 第一次联网打开过的页面，以后**没信号时也能打开**，看到的是最后一次联网时的数据，顶部会有黄色的「离线模式」提示。
- 没信号时新建的任务和照片会存在手机里，右上角显示「待同步」，**联网后自动上传**。
- 系统更新后，手机上会提示「有新版本」，点「刷新」即可。

## 9. 日常维护

### 9.1 系统在后台运行

安装后有两个服务，**电脑开机后自动启动**，程序出错会自动重启，平时不用管：

| 服务名 | 作用 |
|---|---|
| WorkRecord App | 系统本身 |
| WorkRecord HTTPS (Caddy) | 加密网页入口，以及证书下载页 |

**查看状态：** 按 Win + R，输入 `services.msc` 回车，找到上面两个服务，状态应该是「正在运行」。右键可以「重新启动」。

### 9.2 打不开了怎么办（按顺序检查）

1. 服务器电脑**开着吗**？是不是睡眠了或者断网了？
2. 在服务器电脑上打开 `http://127.0.0.1:8000`：
   - **能打开**：系统本身正常，问题在网络、HTTPS 或手机证书 → 看 [第 11 节常见问题](#11-常见问题)。
   - **打不开**：在 `services.msc` 里重新启动「WorkRecord App」，等 1 分钟再试。
3. 还不行：打开 `C:\WorkRecord\logs`，把 `WorkRecordApp.err.log` 文件发给技术负责人。

### 9.3 更新到新版本

1. 按第 5 步下载新版本，解压到一个**新的文件夹**，例如 `D:\shift-worklog-new`。
2. 用管理员身份打开 PowerShell（同 6.1），一行一行输入：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```

```powershell
cd D:\shift-worklog-new\deploy\windows
```

```powershell
.\update.ps1
```

3. 更新脚本会**先自动备份**，然后停止系统、更新程序、升级数据库、重新启动。看到「更新完成」就好了。更新期间（几分钟）系统暂时用不了，**建议在交接班之外的时间更新**。
4. 数据、图片、密码、证书都会保留，手机不用重装证书。

### 9.4 修改服务器 IP 地址

改地址分两件事：先让电脑**真的换到新 IP**，再告诉系统新地址是什么。

**① 让电脑换到新 IP**：请网管在路由器里改绑定，或按 3.2 改静态 IP。改好后在 `cmd` 里运行 `ipconfig`，确认「IPv4 地址」已经是新的。

**② 告诉系统新地址**（二选一）：

**办法 A：用改地址脚本（推荐）。** 用管理员 PowerShell 一行一行输入，最后一行的 IP 换成新的：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```

```powershell
cd C:\WorkRecord\app\deploy\windows
```

```powershell
.\set-address.ps1 192.168.1.60
```

> 如果 `C:\WorkRecord\app\deploy\windows` 里没有 `set-address.ps1`（2026-11-23 以前装的版本没有），就先下载最新版本解压，在**新下载的文件夹**的 `deploy\windows` 里运行同样的命令。

想同时用电脑名访问的话，用英文逗号隔开并加引号：`.\set-address.ps1 '192.168.1.60, worklog-server'`

看到绿色的「地址已修改。」就好了。

**办法 B：用记事本手动改（不用下载任何东西）。**

1. 用管理员身份打开记事本：开始菜单搜「记事本」→ 右键 → 以管理员身份运行。
2. 记事本里「文件 → 打开」，文件类型选「所有文件」，打开 `C:\WorkRecord\tools\WorkRecordCaddy.xml`。
3. 找到这一行，把 `value="..."` 引号里的旧 IP 改成新 IP，保存：

```
<env name="SITE_HOSTS" value="192.168.1.50"/>
```

4. 按 Win + R，输入 `services.msc` 回车，找到「WorkRecord HTTPS (Caddy)」，右键 →「重新启动」。

**③ 改完以后**

- 数据、密码都不受影响。**已经装过证书的手机不用重装证书**，只要用新地址打开 `https://新IP` 即可。
- 手机桌面上的旧图标指向旧地址，打不开了：用新地址打开后，重新「添加到主屏幕」，再删掉旧图标。
- 新手机照常先打开 `http://新IP/install` 安装证书。

## 10. 备份与恢复

### 10.1 自动备份

每天凌晨 **03:40** 自动备份到安装时选的文件夹（默认 `C:\WorkRecord\backups`）：

| 文件夹 | 内容 |
|---|---|
| `db` | 数据库，文件名类似 `workrecord-20261122-0340.dump`，**保留 30 天** |
| `uploads` | 任务照片 |
| `caddy-pki` | HTTPS 证书（丢了的话所有手机要重装证书） |
| `config` | 配置文件，里面有密码，**不要外传** |

**建议每周检查一次：** 打开 `C:\WorkRecord\logs\backup.log`，最后几行应该是当天的「备份完成」。

**最好再拷一份到别处**（U 盘、另一台电脑、网盘）。备份和服务器放在同一块硬盘上的话，硬盘坏了会一起丢。

### 10.2 手动备份一次

用管理员 PowerShell 输入：

```powershell
powershell -ExecutionPolicy Bypass -File C:\WorkRecord\app\deploy\windows\backup.ps1
```

### 10.3 恢复数据（数据库坏了或误操作时）

> 恢复会用备份**覆盖**当前数据，备份之后新录入的内容会丢失。不确定的话先问技术负责人。

1. 用管理员 PowerShell 停止系统：

```powershell
Stop-Service WorkRecordCaddy, WorkRecordApp
```

2. 找数据库密码：用记事本打开 `C:\WorkRecord\app\backend\.env`，`DATABASE_URL=` 那一行里 `workrecord:` 和 `@` 之间的那一串就是密码。
3. 恢复数据库（把 `数据库密码` 和备份文件名换成实际的）：

```powershell
$env:PGPASSWORD = '数据库密码'
```

```powershell
& 'C:\Program Files\PostgreSQL\17\bin\pg_restore.exe' --clean --if-exists -h 127.0.0.1 -U workrecord -d workrecord 'C:\WorkRecord\backups\db\workrecord-20261122-0340.dump'
```

4. 恢复照片：

```powershell
robocopy C:\WorkRecord\backups\uploads C:\WorkRecord\data\uploads /E
```

5. 启动系统：

```powershell
Start-Service WorkRecordApp, WorkRecordCaddy
```

### 10.4 换一台服务器电脑

1. 在新电脑上按第 3～6 步重新安装（第 4 步 PostgreSQL 也要装）。
2. 把旧电脑的备份文件夹整个拷到新电脑，按 10.3 恢复数据库和照片。
3. 再把备份里的证书和配置放回去，这样**手机不用重装证书，大家也不用重新登录**：
   - 把 `caddy-pki` 文件夹里的内容复制到 `C:\WorkRecord\data\caddy\caddy\pki`（覆盖）。
   - 把 `config\backend.env` 复制到 `C:\WorkRecord\app\backend\.env`（覆盖）。
4. 重启两个服务。新电脑的 IP 和旧电脑不一样的话，再按 9.4 设置新 IP。

## 11. 常见问题

| 现象 | 原因和处理 |
|---|---|
| 运行脚本时提示「无法加载文件……因为在此系统上禁止运行脚本」 | 没有先运行 `Set-ExecutionPolicy -Scope Process Bypass -Force`，或者是在另一个窗口运行的。在同一个窗口里先运行这一行。 |
| 提示「请右键以管理员身份运行 PowerShell」 | 没有用管理员身份打开，按 6.1 重新打开。 |
| 提示「没有找到 PostgreSQL」 | 第 4 步没装，或装的不是默认位置。按第 4 步安装。 |
| 提示 postgres 密码不对 | 密码输错了，重新运行 `.\install.ps1` 再输入一次。忘了密码只能卸载 PostgreSQL 重装（还没有数据时）。 |
| 提示端口 80 或 443 被占用 | 按 3.3 关掉占用的程序，重新运行脚本。 |
| 下载 Python / Caddy 等失败 | 这台电脑上不了外网，或公司防火墙拦截了。请网管放行，或换个能上网的时间再运行。 |
| 手机打不开 `http://IP/install` | 手机和服务器不在同一个网络；或电脑上装了其他安全软件拦截了 80、443 端口，需要在那款软件里放行。 |
| 手机提示「不安全」「证书无效」 | 证书没装好。安卓重装证书；iPhone 检查 8.2 第 4 步「证书信任设置」的开关有没有打开。 |
| 提示「证书和网址不匹配」 | 用了安装时没填的地址访问（例如电脑名）。请用安装完成时显示的地址，或按 9.4 加上这个地址。 |
| 任务一直显示「待翻译」 | 服务器上不了外网，或者没填 DeepSeek Key。到「系统设置」点「测试连接」检查。 |
| 电脑重启后打不开 | 开机后服务要 1～2 分钟才启动好，稍等一下。还不行按 9.2 检查。 |
| 忘了 admin 密码 | 用记事本打开 `C:\WorkRecord\app\backend\.env`，`ADMIN_PASSWORD=` 后面是**第一次安装时**的密码；之后在网页里改过的话，请技术负责人处理。 |

## 12. 附录：安装位置一览

| 位置 | 内容 |
|---|---|
| `C:\WorkRecord\app` | 系统程序（更新时会被替换） |
| `C:\WorkRecord\app\backend\.env` | 配置文件：数据库密码、密钥等。**不要删除、不要外传** |
| `C:\WorkRecord\data\uploads` | 任务照片 |
| `C:\WorkRecord\data\caddy` | HTTPS 证书 |
| `C:\WorkRecord\logs` | 运行日志、备份日志 |
| `C:\WorkRecord\backups` | 默认的备份位置 |
| `C:\WorkRecord\tools` | 辅助程序（Caddy、服务管理程序） |

**卸载**（一般用不到）：用管理员 PowerShell 运行下面的命令。默认只删除服务，数据和数据库都保留：

```powershell
powershell -ExecutionPolicy Bypass -File C:\WorkRecord\app\deploy\windows\uninstall.ps1
```
