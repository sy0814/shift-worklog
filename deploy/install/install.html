第一次使用时，手机需要安装一次本系统的证书，之后打开就不会再提示「不安全」。
Pre prvog korišćenja instalirajte sertifikat jednom. · Install the certificate once before first use.

① 下载证书 · Preuzmi sertifikat · Download certificate
② 打开系统 · Otvori · Open

安卓 Android

  1. 点上面的「下载证书」。Preuzmite sertifikat. · Download the certificate.
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选刚下载的 workrecord-ca.crt（不同手机菜单名字略有不同，可在设置里搜索「证书」）。
    Podešavanja → Bezbednost → Šifrovanje i akreditivi → Instaliraj sertifikat → CA sertifikat. · Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. 用 Chrome 打开系统，菜单 → 添加到主屏幕。Chrome → meni → Dodaj na početni ekran. · Chrome → menu → Add to Home screen.

苹果 iPhone / iPad

  1. 用 Safari 点「下载证书」，提示「已下载描述文件」。U Safariju preuzmite sertifikat. · In Safari, download the certificate.
  2. 设置 → 通用 → VPN 与设备管理 → 点刚下载的描述文件 → 安装。
    Podešavanja → Opšte → VPN i upravljanje uređajem → Instaliraj. · Settings → General → VPN & Device Management → Install.
  3. 必须再做这一步：设置 → 通用 → 关于本机 → 最下面「证书信任设置」→ 打开本证书的开关。
    Obavezno: Opšte → O uređaju → Podešavanja poverenja sertifikata → uključite. · Required: General → About → Certificate Trust Settings → turn it on.
  4. 用 Safari 打开系统，分享按钮 → 添加到主屏幕。Safari → Deli → Dodaj na početni ekran. · Safari → Share → Add to Home Screen.

电脑 Windows

  1. 下载证书后双击 → 安装证书 → 本地计算机 → 将所有证书放入下列存储 → 受信任的根证书颁发机构。然后重启浏览器。
    Instaliraj sertifikat → Pouzdani izdavači osnovnih sertifikata. · Install certificate → Trusted Root Certification Authorities.
