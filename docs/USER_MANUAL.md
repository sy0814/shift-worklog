## 1. 系统能做什么

- **记录每个班做了什么**：每件工作是一条「任务」，写清楚内容、谁做、什么时候开始和完成、拍照留证。
- **交接班**：本班没做完的任务一键「移交」给下一个班，下一班打开首页就能看到上一班交过来的工作。
- **三种语言**：中文、塞尔维亚语、英语任意一种写，系统自动翻译成另外两种，三种同时显示。
- **自动知道谁在班**：按排班自动算出现在是哪个班组在上班、下一个是谁、每个人忙不忙。
- **项目和定期巡查**：大活拆成子项目分给不同班组；固定周期的检查到时间自动派发。
- **手机能用，没网也能用**：现场 Wi-Fi 不好的地方也能录入、开始、完成任务，有网后自动上传。
- **所有修改都有记录**：谁在什么时候改了什么，管理员都能查到，记录不能删改。

## 2. 打开系统、装到手机上

- 在车间电脑或手机的浏览器里打开管理员告诉你的地址（例如 `https://192.168.1.10`）。
- **手机第一次使用**：先按管理员给的说明装一次「根证书」（打开 `http://服务器地址/install` 有中 / 塞 / 英图文说明），之后浏览器才不会提示「不安全」。
- **装到主屏幕**：
  - 安卓 Chrome：菜单 →「添加到主屏幕」。
  - iPhone Safari：分享按钮 →「添加到主屏幕」。
  - 装好后像 APP 一样从桌面打开。
- **切换语言**：右上角（手机在「更多」里）选 中文 / Srpski / English。
- 有新版本时右上角会提示，点「刷新」即可（不会自动刷新，避免冲掉你正在填的内容）。

## 3. 登录

**全厂有多个车间时**，打开地址先看到「全厂导航」：每个车间一张卡片，写着此刻哪个班组在班。点自己的车间 →「进入」到登录页（登录页上方写着车间名，「切换车间」回到导航）。手机会记住上次选的车间，下次直接到登录页。只有一个车间时没有这一步。

登录页有两种方式：

| 方式 | 谁用 | 怎么登录 |
|---|---|---|
| **管理账号** | 管理员、班长、副班长等 | 输入用户名和密码（用户名一般是工号） |
| **个人账号** | 成员 | 选自己的班组 → 点自己的头像 → 输入自己的个人密码（只列当前车间的班组） |

- **第一次登录**：密码是管理员设置的「默认密码」，登录后系统会要求你**先改密码**才能继续。新密码不能和默认密码一样。
  - 管理账号的密码至少 6 位。
  - 个人账号的个人密码至少 4 位（可以是数字）。
- 密码连续输错 5 次，这个人会被锁 10 分钟（不影响别人）。急用请找管理员解锁。
- 忘了密码：找班长或管理员重设，重设后再登录也要先改密码。
- **个人账号**：30 分钟不操作会自动退出。几个人共用一台手机时，用菜单里的「换人」切换。
- 改密码：右上角菜单（手机在「更多」里）→「修改密码」。

## 4. 页面一览

电脑在顶部导航。手机在底部标签栏（首页 / 任务 / 出勤 / 排班），其他页面在「更多」里。

| 页面 | 内容 | 谁能看到 |
|---|---|---|
| 首页 | 超时警示、当前班和下一个班、人员状态、交接班 | 所有人 |
| 任务 | 所有任务的列表、搜索、筛选、新建 | 所有人（成员只看本班组和自己参与的） |
| 出勤 | 每个人每天上什么班、请假、调班、加班 | 所有人 |
| 排班 | 排班日历、班组调班、班组管理、班次时间、节假日 | 所有人（能改什么看权限） |
| 项目 | 两个标签：项目 / 定期巡查 | 所有人 |
| 设备台账 | 设备清单和每台设备的任务 | 所有人 |
| 管理（下拉） | 员工名册、术语表、AI 工作量分析、角色权限、账号管理、操作记录、系统设置 | 系统管理员（车间管理员只有员工名册、AI 工作量分析；班长能进员工名册给成员重设密码） |

> 多个车间时，顶栏系统名称旁边显示当前车间。首页、交接班、任务、出勤、排班、项目、巡查、设备都只显示当前车间的（见第 12 章）。

> 每个人能做什么由「角色权限」决定（见 [11.2](#112-角色权限)）。下面说的是默认设置。

### 4.1 界面约定（几个到处都一样的地方）
- 表格的「操作」一栏在最右边：电脑上所有按钮排成一行；手机上只放最常用的一两个，其余点「⋯」。删除总在最后、红色。
- 手机上页面顶部的按钮两个一排、一样宽。
- 手机上的排班日历用一个字表示班次（白 / 中 / 夜 / 休，塞语 P / D / T / S），点住能看全称。

## 5. 成员：日常使用

成员默认可以：看本班组的任务，**开始 / 完成自己参与的任务**，给自己参与的任务**拍照**。

### 5.1 找到自己的任务
- 首页下半部分是**交接班**：上一班移交过来的、本班待办、本班完成。
- 首页上方的班次卡片 → 点开「人员状态」，能看到自己手上的任务。
- 「任务」页最上面可以切换 **「我的任务 / 班组任务」**：「我的任务」= 自己是带队人或参与人员的（成员默认看这个），「班组任务」= 本班组的。「班组任务」下还可以在「人员」框里选一个人（能输入名字搜索），只看他做过的任务（他带队或参与的），用来查某个人干了什么。还可以搜索、按状态 / 日期筛选。

### 5.2 开始、完成
1. 点任务卡片打开详情。
2. 开始干活时点 **「开始」**，状态变成「进行中」，系统记下开始时间。
3. 干完点 **「完成」**，弹出确认窗口，里面可以顺手写一条**班次日志**（选填，例如「换了 3 个托辊，还有 2 个有异响」），会自动翻译、导出里也有；点「完成」后系统记下完成时间和确认人。
4. 点错了：进行中可以「改回未开始」。

> 任务一旦「已完成」，只有管理员能再改。

### 5.3 拍照
- 任务详情 →「拍照」直接调相机，或「从相册选择」。电脑上选文件。
- 照片会自动压缩后上传，原图的拍摄时间会保留（读照片里的时间）。
- 可以一次选多张。

### 5.4 班次日志
任务详情下面有 **「班次日志」**：干活过程中随时记一笔，例如「油泵压力 0.15 MPa，偏低，已换滤芯」「缺一个密封圈，等仓库」。
- 用哪种语言写都行，会**自动翻译**成另外两种；每条自动记下谁写的、几点、哪个班。
- 可以写很多条。任务**移交**后，下一班在新任务里能看到前面所有班写的日志，接着往下写。
- 任务卡片上的 **📝 N** = 这条任务（含移交前各班）一共有几条日志，交接班时一眼能看出上一班写了东西。
- 写错了：自己写的可以删（删除会留记录）。
- 没网时也能写，存在手机上，联网后自动上传，班次按你写的时间算。
- 已完成、已移交的任务不能再写（移交过去的在新任务上接着写）。
- 导出 Excel 时，日志在单独的一张表「班次日志」里。

### 5.5 看不懂别的语言？
每条任务的大字是你当前界面语言，下面小字是另外两种语言；标「原文」的是录入人写的原话。

## 6. 班长 / 副班长：安排工作和交接班

班长、副班长默认能管理**本班组**（以及当天和本班组合并显示的班组，例如白班时的常白班）的工作。

### 6.1 首页
- **红框警示**：没做完、而且从第一次录入起超过 24 小时（或已经移交 3 次以上）的任务，置顶标红。管理员可以改这两个数。
- **班次卡片**：当前在班的班组（合在一起上班的都写出来，例如「3班 + 常白班」）和下一个接班的班组，下面两行人数：**👔 管理** 在岗 / 忙碌 / 空闲（此刻在班的管理人员，见下）；**👷 电工** 在岗 / 忙碌 / 空闲（班组里的人，还有请假、休息中的人数）。
  - **管理人员** = 能给整个车间所有班组派活的人（角色的「新建任务」权限是「本车间」或「全厂」，例如车间管理员）。他们不跟班组排班，**请在「员工名册 → 长期排班」给每人设个人循环**（例如 7 天「白 白 白 白 白 休 休」，每人循环第 1 天错开 = 休息日错开），系统按这个判断在不在班。没设的会在人员状态里提醒。
  - 点卡片打开**人员状态**：最上面是在班的**管理人员**，然后是班长、副班长，再下面按班组列出每个人（头像、状态、手上的任务）。
  - 状态：**忙碌**（手上有没做完的任务）、**空闲**、**请假 / 缺勤**、**休息中**（有自定义上班时间的人，例如午休，会提示「休息中，14:00 回来」；不算在岗，但照样可以勾选、给他安排任务）。
  - 上班时间延伸到下一个班的人（例如白班 7–12、14–17），在「下一个接班（中班）」里也会列出来，标「到 17:00」，计入中班在岗，也能给他安排任务；过了 17:00 就不再算。
  - 勾选几个人 →「给选中的人添加任务」，或「设置加班」。
  - 名字旁边的「为什么？」：看这个人今天为什么上这个班（见 9.6）。
- **交接班**：上一班移交过来的、本班待办、本班完成。默认看本班组（管理员看此刻在班的班组）；显示的不是此刻在班的班时（例如本班组在休息，看的是它的下一个班），「交接班」旁边会写「正在看：1班 夜班 11-25 · 下一个班」。
- **今日排班**（班次卡片下面，默认收起，展开 / 收起会记住）：看今天每个班组上什么班；**点某个班组 = 在下面看它的交接班**，看完点「回到当前」。

### 6.2 新建任务
「任务」页或首页 →「新建任务」：
- **工作内容**：用任何一种语言写，保存后自动翻译（几秒钟）。
- **类型**：故障维修 / 计划检修 / 巡查 / 其他（默认「其他」；定期巡查生成的任务自动是「巡查」）。设备统计按这个分，**设备坏了来修的请选「故障维修」**。任务卡片上会标出故障维修、计划检修。
- **设备**（可不选）：关联到设备台账里的某台设备。
- **带队人员** + **参与人员**：只能选**这个班次在岗的人**。其他班组的人要先在「出勤」里安排来本班。
- 状态：可以直接建成「进行中」或「已完成」（补录用）。
- 开始 / 完成时间、遗留问题、照片。
- 任务归属哪个班次自动判断：
  - 在班时录入 → 当前班；
  - 下班 2 小时内补录 → 刚结束的班；
  - 提前安排 → 本班组的下一个班。

### 6.3 修改、校对译文
- 任务详情 →「编辑」可以改内容、人员、时间、遗留问题。
- 改了原文会问你：重新翻译，还是保留现有译文。
- 译文不准确：「校对译文」手动改。改过的标「人工校对」，以后机器翻译不会覆盖。

### 6.4 移交（交接班）
本班没做完的任务交给下一个班：
1. 任务详情 →「移交」，或在首页交接班里勾选多条 →「移交所选」。
2. 系统已选好**默认接收班组**（按交接顺序：夜 → 白 → 中 → 夜；常白班交给当天中班），也可以改成别的班组。要交给**别的车间**，在下面「其他车间」里选那个车间的班组。
3. 填「交接说明」（可不填），会显示为新任务的遗留问题。
- 移交后原任务变「已移交」，接收班组那边出现一条新任务，带着内容、译文和照片，不带参与人员（由接收班组重新安排）。
- 一条任务被移交了几次、一共拖了多久都会记录，超过阈值进红框警示。

- **不可移交**：新建或编辑任务时把「可移交」关掉，这条任务就一直留在本班组：没有「移交」按钮，首页交接班里它前面是灰色方框（勾不上），卡片上有「🔒 不可移交」标签，也不会自动移交。项目的子项目跟着项目的设置。

### 6.5 废弃
不用做了的任务 →「废弃」，**必须写原因**。废弃后不能再改。

### 6.6 班长还能做
- 出勤：给本班组的人请假、调班、批量安排、设置加班（见第 8 章）。
- 排班：本班组的「班组调班」、和别的班组互换（见第 9 章）。
- 项目、定期巡查：给本班组建（见第 7 章）。
- 设备台账：新增、修改设备。
- 员工名册：给本班组用个人账号的成员**重设个人密码**。
- 导出 Excel：本班组的任务和出勤。

## 7. 项目和定期巡查

都在「项目」页，两个标签。

| | 项目 | 定期巡查 |
|---|---|---|
| 用来 | 一次性的大活，拆成多步，例如「1# 球磨机大修」 | 固定周期的例行工作，例如「每周一检查皮带机托辊」 |
| 怎么生成任务 | 建的时候立刻生成 | 到时间自动生成 |
| 什么时候算完 | 所有子项目都完成（或废弃）才算完成 | 每次派发的各自完成，巡查项一直有效 |

### 7.1 项目
1. 「项目」→「新建项目」：名称（任何语言，自动翻译）、截止日期、**可移交 / 不可移交**。
2. 加子项目，每个子项目选**派给谁**：
   - **班组**：班长再安排人；
   - **某个人**：他是带队人，任务归他所在的班组，从他下一个上班的班开始。选人时会显示每个人下一个班是什么时候。
3. 子项目就是普通任务，会出现在对应班组的交接班里，任务卡片上有「📁 项目名 完成数/总数」。
4. 人休息或请假了 → 子项目「改派」给别人或别的班组。
5. **可移交**的项目：子项目本班没做完，下班 30 分钟后系统自动交给正在上班的班组。**不可移交**的一直留在原班组，手动也不能移交。
6. 所有子项目都「已完成」或「已废弃」，项目自动关闭；之后再加子项目会重新打开。

班长只能把子项目分给本班组（和合并显示的班组）；管理员可以分给任何班组。

### 7.2 定期巡查
1. 「项目」→「定期巡查」标签 → 新建。
2. 填内容，选**周期**：
   - 每天、每隔 N 天；
   - 每周几（可多选）；
   - 每月几号（可多选；29～31 号在小月按最后一天）；
   - 每年某几天（可每隔 N 年）；
   - 按班次（白 / 中 / 夜，每隔 N 个班）。
3. 选**派给谁**：
   - 到时间正在上班的班组；
   - 或固定某个班组：它休息就顺延到它的下一个班，可以预设参与人员。
4. 编辑时下面会预览「接下来 5 次」的时间，确认没设错。
5. 可以加**小项目**：每次到时间自动建一个项目，每个小项目是一个子项目（可以分别指定班组或人）。适合「每月设备月检，分 5 项」这种。
6. 「立即派发」可以马上派一次。派发记录里能看到每次派给了谁，有小项目的可以「查看项目」。
7. 已经派发过的巡查项不能删除，不需要了就**停用**。

班长只能管「固定派给本班组」的巡查项，其他的只能看。
- **可移交**开关：关掉后，生成的任务（有小项目时 = 生成的项目）一直留在派给的班组，不能移交。巡查列表里这种巡查项名称下面有「不可移交」标签。

## 8. 出勤、调班、加班

「出勤」页是一张表：每个人一行，每天一格，显示上什么班（白 / 中 / 夜 / 休）、请假等。

- **默认每个人都按排班出勤**，不用每天录；只需要记例外。
- 点格子可以改：出勤（选实际班次）、请假、病假、缺勤、休息，或「恢复按排班」。点格子还能查看**这个人这天做了哪些任务**。
- 格子弹窗右上角「为什么？」：展开看这一格是怎么得出来的（见 9.6）。
- **批量安排**：多个人 × 连续多天一起设置。例如周末安排几个人来顶 2 班的夜班：选人、选日期、出勤、顶「2 班」。
- **两人换班**：两个人某天的班互换（可以跨班组、可以和休息的人换）。
- 来支援的人会在被支援班组的表里显示为「支援」。
- **设置加班**：给几个人或整个班组设置「某个班次后加班到几点」。首页人员状态里显示「加班至 HH:mm」，出勤表和导出里有加班小时数。
- 格子上有 ⏱ 的人有自定义上班时间（例如 7–12、14–17），鼠标停上去能看到具体时间。
- **导入出勤表**：先下载模板，只填例外（日期、工号、姓名、状态、班次、备注），导入时整个文件先检查，有一行错就全部不导入，并告诉你哪行错了。

班长能改本班组的人，也能把别的班组的人安排来本班组上班；管理员能改所有人。所有修改都留记录。

## 9. 排班

### 怎么改排班？（四类）
所有改排班的地方分成四类，「排班」页和「出勤」页顶部的「怎么改排班？」可以展开看，点「去改」直接过去：

| | 长期（一直有效） | 某天（只管那几天） |
|---|---|---|
| **班组** | 班组的循环：「排班 → 班组管理」 | 整个班组改班、两个班组互换：「排班 → 排班日历 → 班组调班」 |
| **个人** | 换班组、个人循环：「员工名册 → 长期排班」 | 请假、顶班、改班次、批量安排、两人互换：「出勤」 |

**谁优先**：个人某天 > 个人长期 > 班组某天 > 班组长期。例如常白班调成休息，按个人循环上班的人照样上班；给某人改了出勤，就以出勤为准。

「排班」页：

### 9.1 排班日历
每天每个班组上什么班。上方会提示本月的问题，例如某个班次没有班组上、两个主班组同时上。

- 格子下面的小字：
  - 「原：中」：调过班；
  - 「7-12 14-17」：自定义上班时间；
  - 「按人员」：班组本身休息，但有成员被单独安排来上班，所以班组也算在这个班。**班组这天有「班组调班」时不算**：调成休息就是休息，被单独安排的人照样上班，显示在那个班的主班组里。
- 能调班的人点格子 =「班组调班」，弹窗上面有「为什么？」可以展开；不能调班的人点格子 = 直接看「为什么？」（见 9.6）。

### 9.2 班组调班（临时调整）
- **整个班组某几天改上别的班**：白 / 中 / 夜 / 休，或「⏱ 自定义时间」（例如 07:00–12:00、14:00–17:00）。
- **两个班组互换**某几天的班；再换一次就换回来了。
- 「恢复按排班」撤销调整。
- 保存后会提醒：这几天**哪些人不受这次调班影响**（按个人循环上班的、那天有出勤记录的，以他们自己的为准），以及有没有班次没人上。
- 调整后首页、交接班、默认出勤、巡查派发都按新的算。保存后如果有班次没人上会提醒你。
- 班长能调本班组；互换时只要其中一个是本班组。

### 9.3 班组管理（管理员）
- **每个班组一个循环**：几天一循环、循环里每天上什么、哪天是循环第 1 天。
  - 快速填：「四班三倒」（白白中中夜夜休休）、「周一到周五」、「每周休一天」。
  - 每天的格子右上角 ⏱ 可以设具体上班时间，可以分几段（例如上午 7–12、下午 14–17），最后一段可以跨过半夜。
  - 勾「节假日休息」：节假日休，调休上班日照常上。
- **类型**：按循环 / 不固定（平时休息，靠调班或给成员单独安排）。
- **主班组**：1～4 班这种在首页单独显示的班组。不是主班组的（常白班、临时组）会合并进同一班次的主班组一起显示，两边班长都能操作对方的任务。
- **临时班组**：设有效期，过了有效期就算休息。
- 名称只填一种语言也行，会自动翻译。
- 没用过的班组可以删除；用过的设结束日期。

### 9.4 个人长期排班
有的人和班组排班不一样（例如每个人休息日不同）：「员工名册」→ 这个人的「长期排班」，设**个人循环**，或从某天起换到别的班组。换班组后以前的出勤不变。按个人循环上班的人不受班组调班影响。

### 9.5 班次时间、节假日（管理员）
- 班次时间：三个班的开始时间（默认 07:00 / 15:00 / 23:00）。
- 节假日 / 调休上班日：常白班这类「节假日休息」的班组用。

### 9.6 为什么？（这个班是怎么来的）
谁能看「为什么？」由「管理 → 角色权限」里的 **「看排班原因（为什么？）」** 决定：本班组 / 本车间 / 全厂 / 不能。默认班长、副班长、车间管理员是本车间，成员不能。

一个人某天上什么班，可能被好几样东西影响：班组的循环、节假日、班组调班、个人排班、换班组、出勤页的修改（请假、顶班）……
看不明白时点「为什么？」，系统按**判定的先后**一条条列出依据，例如：

1. 名册：属于「1班」
2. 按「1班」的排班
3. 循环第 5 / 8 天，写的是：夜班
4. 出勤记录（手工修改）：出勤 · 顶「4班」 —— 管理员 设置于 11-25 14:18，备注：4班缺人
5. 去顶「4班」的班、没写班次 → 按「4班」当天的中班
6. 中班由「4班」单独显示

- **标黄的步骤**改变了前面的结果（调班、请假、顶班、节假日等），一般就是你要找的原因；每条都写了是谁、什么时候设的、备注。
- 想改：每一步后面有「去修改」链接（例如「改出勤」「改这次调班」「改长期排班」「改班组排班」「改节假日」），点了直接打开那个人 / 那个班组 / 那一天的修改窗口；没有权限的不显示。撤销就在打开的窗口里点「恢复按排班」。
- 三个地方能看：出勤页的格子、排班日历的格子、首页人员状态里的名字。

## 10. 设备台账

「设备台账」页：设备编号、名称、区域、型号规格、备注。

- **新增设备**：编号不能重复；名称、区域、备注只填一种语言就行，保存后自动翻译另外两种。只改某个译文会保留你改的；改原文会重新翻译。
- 新建或编辑任务时可以选设备，任务卡片上显示「⚙ 编号 名称」。
- 点设备的**任务数**能看到这台设备的所有任务（未完成 / 全部）。
- **导出 Excel**：三种语言各一列，方便给塞方同事核对。
- **导入 Excel**：按设备编号合并，编号已有就更新、没有就新增。先检查再确认，有一行错就全部不导入。
  - 表头可以用中 / 塞 / 英任何一种。
  - 想指定语言就写「名称 sr」这种，不写语言的列按当前界面语言算。
- 关联过任务的设备不能删除，不用了就取消「在用」（之后建任务时选不到它）。

管理员、班长、副班长默认能管理设备，所有人都能看。

### 10.1 设备统计
「设备台账」页标题旁切到 **「统计」**（管理员、车间管理员、班长、副班长能看）：
- 选时间段（默认最近 90 天，可点「最近 30 / 90 / 365 天」）。
- 上面四个数：故障次数、反复故障的设备、未完成、这段时间没有任务的设备。
- **故障次数最多的设备**（前 10）：条越长故障越多，标「⚠ 反复故障」的是 30 天内故障 3 次以上的，要重点关注。
- **全部设备表**：每台设备的故障维修、计划检修、巡查、其他次数，未完成（超时），平均修好用时（从录入到完成），处理用时，移交次数，班次日志条数，最近一次。点表头可以排序。
- **点任何一台设备**：按时间列出它的每一件事——类型、状态、经过哪几个班、多久修好，以及各班写的班次日志（换了什么、发现什么），点编号打开任务。
- 一件事移交几次也只算一次。
- **导出 Excel**：按当前界面语言。

## 11. 管理员

菜单「管理」下。

### 11.1 员工名册
- 像表格一样：**点格子直接改**，回车或点别处就保存。
- 「添加一行」加人。新加的人会**自动开账号**：
  - 个人账号的角色：用默认密码登录；
  - 管理账号的角色：用户名是工号。
- 「给没账号的人开账号」：一次给名册里还没账号的人都开好。
- 「添加列」加自定义列（例如电话、证书），可改名、删除。
- 导入 / 导出 Excel：按工号匹配，先检查再确认；表里没有的人不会被删除；不认识的表头自动加成新列。
- 每行的按钮：
  - 头像：上传后自动裁成正方形；
  - 账号：开账号、重设密码、停用、解锁；
  - 排班：个人循环、换班组。
- 角色列：设成班长、副班长、成员或自定义角色。

### 11.2 角色权限
- 每列一个角色（内置班长、副班长、成员，可以新增）。每项权限选范围：
  - **不能**；
  - **只限自己**：自己是带队人或参与人员的任务、自己传的照片；
  - **本班组**：含当天合并显示的班组；
  - **本车间**：自己车间的所有班组；
  - **全厂**：所有车间。「看任务」是全厂的人（例如厂长）可以在顶栏切换车间。
- 还有**登录方式**（管理账号 / 个人账号）和**首页单独显示**（在人员状态里单独列在上面）。
- 改完点该列的「保存」。系统管理员不受限制。
- 内置的「车间管理员」角色：本车间里什么都能做（含员工名册、班组管理、AI 工作量分析），见 [12.3](#123-车间管理员)。

### 11.3 账号管理
列出所有登录账号。这里只新建**系统管理员**账号；其他人的账号在员工名册里开。可以重设密码、解锁、停用，「改关联」把账号关联到名册里正确的人。

### 11.4 系统设置
- **系统名称**：显示在顶栏、登录页、浏览器标签，填一种语言会自动翻译。
- **未闭环警示**：超过多少小时、移交多少次算超时。
- **新员工默认密码**（至少 6 位，上线前请改掉 `123456`）。
- **AI 接口**：接口地址、API Key（只显示末 4 位）、翻译模型、分析模型；「测试连接」。
- **存储与备份**：
  - 备份位置（建议放另一块硬盘）；
  - **第二份备份**：U 盘、局域网共享，或 OneDrive / 坚果云 / 百度网盘同步盘这类云盘的同步文件夹，云盘客户端会自动传到云上；
  - 最近一次备份结果、「立即备份」；
  - **服务器报警语言**：服务器上「看门狗」弹窗、事件日志用中文、塞尔维亚语还是英语（给值守服务器的人看，和网页语言无关）；
  - **原图归档**：照片原图超过 N 个月自动搬到另一块硬盘，系统里照常显示。

  系统每天 03:40 自动备份。请每周看一眼「最近一次备份」是不是成功。

- **报警**：备份失败、超过一天没有成功的备份、磁盘快满（少于 5 GB 或 10%）时，管理员**首页顶部会显示红色提醒**。服务停了网页打不开，这种情况由服务器上的「看门狗」每 5 分钟检查：服务停了会自动重启并在服务器电脑上弹窗（详见部署指南 9.5）。

### 11.5 术语表
球磨机、浮选机、皮带机这类专业词的三语对照，翻译时一定按这里的译法。可增删改、导入 / 导出 CSV（方便请塞方同事校对）。翻译失败的任务可以在这里「重试失败的」。

### 11.6 AI 工作量分析
选时间段（最多 93 天）、班组、报告语言 → 生成报告。
- 报告里的数字（出勤、任务数、工时、加班、移交、超时……）都是系统算的，AI 只负责写分析和建议。页面下方有统计表可以核对。
- 报告可以下载、打印。

### 11.7 操作记录
所有修改、登录、移交、导出都在这里，写成「谁 做了什么 对象：旧 → 新」。可按账号、类型、日期筛选。记录不能删改。

### 11.8 导出 Excel
任务列表或出勤页「导出 Excel」：选时间段、班组、人员、语言。导出三张表：
- 任务明细；
- 人员工作量（工时、加班）；
- 出勤。

多人参与的任务，每个人都算全部工时。

## 12. 多个车间（全厂使用）

全厂一套系统，每个车间（例如电气车间、选矿车间、机修车间）像一套独立的系统一样用，但车间之间可以移交任务、借调人员。

### 12.1 车间管理（系统管理员）
「系统设置 → 车间管理」：新增车间（名称填一种语言就行，会自动翻译）、改名、停用、删除。
- 只有一个车间时，界面上完全不显示车间，和以前一样；加了第二个车间后，入口变成「全厂导航」。
- 已有的班组、员工、设备都在原来的车间里（升级时名为「默认车间」，请改成实际名称）。
- 停用的车间不在导航页显示；只能删除空车间（没有班组、员工、设备……）。

### 12.2 给新车间建班组和员工
1. 顶栏点车间名 → 切换到新车间（系统管理员能切换；「全厂导航」也在这个菜单里）。
2. 「排班 → 班组管理」加这个车间的班组（例如四个倒班主班组 + 常白班）。每个车间有自己的主班组、交接顺序和排班检查，互不影响。
3. 「管理 → 员工名册」加人（新加的人属于当前车间），把车间负责人的角色设成「车间管理员」。

### 12.3 车间管理员
内置角色「车间管理员」：权限范围都是「本车间」，用管理账号登录。
- 能做：本车间所有任务、移交、出勤、调班、加班、项目、巡查、设备、导出；**员工名册**（加人、改信息、改班组、设角色、开账号、个人排班、导入导出）；**班组管理**；**AI 工作量分析**。新建任务时可以选班组、分给本车间任何人。
- 不能做：别的车间的事；给人设「全厂」范围的角色；车间、角色权限、账号管理、术语表、系统设置、操作记录（这些是系统管理员的）。
- 名册里的自定义列只有系统管理员能加减。

### 12.4 车间之间往来
- **移交给别的车间**：移交时在「其他车间」里选班组。接收的车间在首页「上一班移交过来」里看到，任务卡片上写着「← 电气车间 · 3班」。移交后原车间的班长看不到对方那边的新任务（除非自己参与）。
- **借调人员**：在出勤页把别的车间的人「批量安排」到本车间的班组（顶班组），他就出现在本车间的在岗人员里，可以分配任务，工时算在他自己名下。
- **调到别的车间**：员工名册里把他的班组改成别的车间的班组（系统管理员，或两边都能管的人），以前的出勤不变。

### 12.5 全厂查看
- 系统管理员、以及「看任务」范围是「全厂」的角色（可以在「角色权限」里新建，例如「厂长」）能在顶栏切换车间，看每个车间的首页、交接班、出勤、排班。
- 其他人只能看自己的车间。

## 13. 没有网络的时候

现场有 Wi-Fi 死角也能用（要先在有网的地方打开过一次系统）：

| 操作 | 没网时 |
|---|---|
| 打开系统、看任务 | 能看，显示的是最后一次联网时的数据（页面顶部会提示「离线模式」） |
| 打开任务详情 | 首页和任务列表里的未完成任务，联网时已经存好，可以打开 |
| 新建任务（含照片） | 存在手机上 |
| 开始 / 完成任务 | 存在手机上，按你点的时间记 |
| 给任务补照片 | 存在手机上 |
| 写班次日志 | 存在手机上，按你写的时间算班次 |
| 移交、废弃、改出勤等 | 需要联网 |

- 存在手机上的内容，右上角有「待同步」数字，任务卡片上显示「⏳ 待同步」。
- **联网后自动上传**，也可以点「待同步」→「立即同步」。
- 如果离线期间别人已经改了同一条任务的状态，你的操作不会覆盖别人的，会提示你。
- 退出登录会清掉手机上缓存的页面数据，但**还没上传的内容会留在手机上**，要**同一个人再登录**后才会继续上传。几个人共用一台手机时，最好等「待同步」清零再「换人」。

## 14. 常见问题

**新建任务时找不到某个人？**
只能选这个班次在岗的人。他今天休息或不在这个班 → 先到「出勤」把他安排来本班（出勤 + 班次 + 顶本班组），再建任务。

**翻译一直显示「翻译中」？**
一般几秒钟就好。服务器连不上外网或 AI 接口有问题时会先保存原文，系统每 2 分钟自动重试。一直不好请联系管理员检查「系统设置 → AI 接口」。

**任务点不了「编辑」？**
已完成的任务只有管理员能改；已移交、已废弃的不能再改；成员只能开始 / 完成自己参与的任务。

**首页显示的班组不对？**
看「排班 → 排班日历」当天的安排，是不是有调班、节假日设置。管理员检查「班组管理」里的循环和「循环第 1 天」。

**有人分上午、下午两段上班，会不会在两个班都出现？**
按和哪个班重叠最多算（7–12、14–17 算白班），出勤和交接都记在白班。中间休息时显示「休息中」和几点回来（不算在岗，但能安排任务）。他 15–17 点还在，所以提前看「下一个接班（中班）」时也会列出他，标「到 17:00」、计入中班在岗。

**不固定班组的人今天被安排上班，首页看不到？**
在「出勤」里给他安排了班次（或设了个人循环）后，这个班组当天会自动算在那个班，合并进那个班次显示，日历上标「按人员」。如果这个班组当天有「班组调班」，就按调班算（班组不算在班），但他本人照样上班，显示在那个班的主班组里、能被安排任务。

**手机提示连接不安全？**
没装根证书，按 `http://服务器地址/install` 的说明装一次。

**忘记密码 / 被锁？**
找班长（成员的个人密码）或管理员重设、解锁。
