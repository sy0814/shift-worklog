# 排班场景表

> 这份文件**既是说明，也是测试**：`backend/tests/test_scenarios.py` 逐条读下面的「设置」，
> 按表格检查系统算出来的结果。表格里写错了或系统算错了，测试都会失败。
> 想确认「某种情况系统会怎么排」，先在这里找；找不到就加一个场景（写法见最后）。

## 怎么读

- **设置**：这个场景里有哪些班组、员工、调班、出勤记录。「标准排班」= 1～4 班四班三倒 + 常白班（见场景 1）。
- **表格**每行检查一项：
  - **谁**：`班组「X」`、员工 `「X」`，或 `时刻 HH:MM`（那个时刻属于哪个班）。
  - **结果**：白 / 中 / 夜 / 休，有自定义上班时间时后面写出时间；员工还可能是请假 / 病假 / 缺勤，「出勤」= 出勤但没有班次；顶别的班组时写「（顶 X）」。
  - **原因**：改变了结果的那几步，和页面上「为什么？」里**标黄**的步骤一致（班组调班、节假日、调休上班、不在有效期、按人员、个人循环、出勤记录、顶班）。「—」= 就是按循环排的。
  - **显示在**：这个班次合并显示在哪个主班组那一组（首页、交接班）。「—」= 不上班或这个班次没有主班组。
  - 空着的格子不检查。

## 判定顺序（后面的覆盖前面的）

1. **名册**：这天属于哪个班组，跟班组排班还是个人循环（按变更记录的生效日期）
2. **循环**：班组（或个人）的循环里这天写的什么；打开「节假日休息」的，节假日休息、调休上班日按主要班次上
3. **临时班组有效期**：有效期以外一律休息
4. **班组调班**：整个班组这天改上别的（个人循环的人不受影响）
5. **出勤记录**（导入 / 手工改）：请假、顶班、改班次……以它为准
6. （只影响**班组**算不算在班）非主班组本身休息、但有成员被单独安排上班 → 班组也算在这个班（「按人员」）。
   **班组这天有班组调班时不算这一条**：明确写下的设置优先于推算出来的（2026-11-25 起）

## 怎么加一个场景

复制一个「## 场景 N：…」，改设置和表格，跑 `python -m pytest tests/test_scenarios.py`。设置的写法（每行一条，以「- 」开头）：

| 写法 | 意思 |
|---|---|
| `标准排班` | 1～4 班四班三倒（基准 2026-11-01）+ 常白班 |
| `班组「X」：循环 白 白 中 休，第 1 天 2026-11-01` | 新班组；循环每天用空格隔开，可写 白 / 中 / 夜 / 休 或 `07:00-12:00,14:00-17:00`。后面可加「，主班组」「，节假日休息」「，有效期 A 至 B」（结束可省略） |
| `不固定班组「X」` | 平时休息、只按调班安排的班组（也可加有效期） |
| `节假日 2026-12-25` / `调休上班 2026-12-26` | 多个日期用「、」隔开 |
| `班组调班：「X」2026-11-25 改为 中` | 改为 白 / 中 / 夜 / 休 或时间段（和原排班一样的不算，和页面一致） |
| `员工「X」属于「Y」` | 一直以来属于 Y |
| `员工「X」从 2026-12-01 起属于「Y」` | 从某天起换班组；后面可加「，个人循环 白 白 休，第 1 天 2026-12-01」 |
| `出勤：「X」2026-11-25 请假` | 请假 / 病假 / 缺勤 / 休息 / 出勤；出勤后面可加「顶「Y」」和「白班 / 中班 / 夜班」 |
